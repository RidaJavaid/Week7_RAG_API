Machine learning is a field of artificial intelligence in which computer systems learn patterns from data instead of relying only on hand-written rules. Supervised learning uses labeled examples, such as emails marked spam or not spam. Classification predicts categories, while regression predicts continuous numeric values. Unsupervised learning works with unlabeled data and includes clustering and dimensionality reduction. Training data is used to fit model parameters. Validation data helps tune choices such as hyperparameters, and test data estimates final generalization on unseen examples. Overfitting occurs when a model memorizes training details and performs poorly on new data. Regularization, simpler models, more data, and early stopping can reduce overfitting. Underfitting occurs when a model is too simple to capture important patterns. Features are measurable input variables used by a model. Labels are target outputs in supervised learning. Accuracy is the fraction of correct predictions, while precision and recall are useful when class balance or error types matter. Cross-validation repeatedly changes the train-validation split to estimate performance more robustly. A baseline is a simple reference method used to decide whether a more complex model actually helps.
